# Post Widget

You can **embed messages from public groups and channels** anywhere. Here’s what an embed of a Telegram message looks like when included on a web page:

<div><br>
<script async src="https://telegram.org/js/telegram-widget.js?1" data-telegram-post="durov/68" data-width="100%"></script>
<br><br>
</div>

To get the HTML-code for embedding a message, just **open its t.me link** (e.g., [t.me/durov/43](https://t.me/durov/43)) in a web browser and click **< > EMBED**:
