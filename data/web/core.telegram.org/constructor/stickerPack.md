# stickerPack

A stickerpack is a group of stickers associated to the same emoji.  
It is **not** a sticker pack the way it is usually intended, you may be looking for a [StickerSet](/type/StickerSet.md).

```tl
stickerPack#12b299d4 emoticon:string documents:Vector<long> = StickerPack;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **emoticon** | [string](/type/string.md) | Emoji |
| **documents** | [Vector](/type/Vector%20t)&lt;[long](/type/long.md)&gt; | Stickers |
