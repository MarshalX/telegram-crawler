```tl

```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **attribute** | [StarGiftAttributeId](/type/StarGiftAttributeId.md) | The attribute (just the ID, without the attribute itself). |
| **count** | [int](/type/int.md) | Total number of gifts with this attribute. |
