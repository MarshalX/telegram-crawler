# messages.webPage

Represents an Instant View webpage.

```tl
messages.webPage#fd5e12bd webpage:WebPage chats:Vector<Chat> users:Vector<User> = messages.WebPage;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **webpage** | [WebPage](/type/WebPage.md) | The instant view webpage. |
| **chats** | [Vector](/type/Vector%20t)&lt;[Chat](/type/Chat.md)&gt; | Chats mentioned in the webpage. |
| **users** | [Vector](/type/Vector%20t)&lt;[User](/type/User.md)&gt; | Users mentioned in the webpage. |
