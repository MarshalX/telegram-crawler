# aiComposeToneExample

An example showing how an [AI composer tone »](/api/ai.md#ai-compose-tones) rephrases a message, used as a preview in the tone picker.

```tl
aiComposeToneExample#f1d628ec from:TextWithEntities to:TextWithEntities = AiComposeToneExample;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **from** | [TextWithEntities](/type/TextWithEntities.md) | The original, un-transformed sample message |
| **to** | [TextWithEntities](/type/TextWithEntities.md) | The same sample message after being rephrased with this tone |

### Type
[AiComposeToneExample](/type/AiComposeToneExample.md)
