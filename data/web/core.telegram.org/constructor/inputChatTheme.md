# inputChatTheme

Set an emoji-based chat theme, returned by [account.getChatThemes](/method/account.getChatThemes.md).

```tl
inputChatTheme#c93de95c emoticon:string = InputChatTheme;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **emoticon** | [string](/type/string.md) | The emoji. |
