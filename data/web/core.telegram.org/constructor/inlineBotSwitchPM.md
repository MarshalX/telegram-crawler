# inlineBotSwitchPM

The bot requested the user to message them in private

```tl
inlineBotSwitchPM#3c20629f text:string start_param:string = InlineBotSwitchPM;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **text** | [string](/type/string.md) | Text for the button that switches the user to a private chat with the bot and sends the bot a start message with the parameter `start_parameter` (can be empty) |
| **start\_param** | [string](/type/string.md) | The parameter for the `/start parameter` |

### Type
[InlineBotSwitchPM](/type/InlineBotSwitchPM.md)
