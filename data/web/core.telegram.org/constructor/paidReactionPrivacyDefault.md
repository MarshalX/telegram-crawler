# paidReactionPrivacyDefault

Uses the default reaction privacy, set using [messages.togglePaidReactionPrivacy](/method/messages.togglePaidReactionPrivacy.md).

```tl
paidReactionPrivacyDefault#206ad49e = PaidReactionPrivacy;
```

### Parameters

This constructor does not require any parameters.

### Type
[PaidReactionPrivacy](/type/PaidReactionPrivacy.md)
