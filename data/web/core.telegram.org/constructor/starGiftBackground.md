# starGiftBackground

Contains the default background palette of a [gift type »](/api/gifts.md#listing-all-possible-collectible-variants).

```tl
starGiftBackground#aff56398 center_color:int edge_color:int text_color:int = StarGiftBackground;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **center\_color** | [int](/type/int.md) | Center color of the background palette, in RGB24 format. |
| **edge\_color** | [int](/type/int.md) | Edge color of the background palette, in RGB24 format. |
| **text\_color** | [int](/type/int.md) | Text color to use on top of the background palette, in RGB24 format. |

### Type
[StarGiftBackground](/type/StarGiftBackground.md)
