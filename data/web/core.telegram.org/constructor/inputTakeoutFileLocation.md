# inputTakeoutFileLocation

Used to download a JSON file that will contain all personal data related to features that do not have a specialized [takeout method](/api/takeout.md) yet, see [here »](/api/takeout.md) for more info on the takeout API.

```tl
inputTakeoutFileLocation#29be5899 = InputFileLocation;
```

### Parameters

This constructor does not require any parameters.

### Type
[InputFileLocation](/type/InputFileLocation.md)
