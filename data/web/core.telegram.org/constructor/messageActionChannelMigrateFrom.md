# messageActionChannelMigrateFrom

Indicates the channel was [migrated](/api/channel.md) from the specified chat

```tl
messageActionChannelMigrateFrom#ea3948e9 title:string chat_id:long = MessageAction;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **title** | [string](/type/string.md) | The old chat title |
| **chat\_id** | [long](/type/long.md) | The old chat ID |

### Type
[MessageAction](/type/MessageAction.md)
