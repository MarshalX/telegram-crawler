# upload.cdnFileReuploadNeeded

The file was cleared from the temporary RAM cache of the [CDN](/cdn.md) and has to be re-uploaded.

```tl
upload.cdnFileReuploadNeeded#eea8e46e request_token:bytes = upload.CdnFile;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **request\_token** | [bytes](/type/bytes.md) | Request token (see [CDN](/cdn.md)) |

### Type
[upload.CdnFile](/type/upload.CdnFile.md)
