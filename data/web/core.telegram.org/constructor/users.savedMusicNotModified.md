# users.savedMusicNotModified

This subset of the songs currently pinned on a user's profile hasn't changed, see [here »](/api/profile.md#music) for more info.

```tl
users.savedMusicNotModified#e3878aa4 count:int = users.SavedMusic;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **count** | [int](/type/int.md) | Total number of songs on the user's profile. |

### Type
[users.SavedMusic](/type/users.SavedMusic.md)
