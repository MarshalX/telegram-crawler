# notificationSoundLocal

Indicates a specific local notification sound should be used

```tl
notificationSoundLocal#830b9ae4 title:string data:string = NotificationSound;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **title** | [string](/type/string.md) | Notification sound title |
| **data** | [string](/type/string.md) | Notification sound identifier (arbitrary data used by the client to identify a specific local notification sound) |

### Type
[NotificationSound](/type/NotificationSound.md)
