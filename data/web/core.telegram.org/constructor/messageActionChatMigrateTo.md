# messageActionChatMigrateTo

Indicates the chat was [migrated](/api/channel.md) to the specified supergroup

```tl
messageActionChatMigrateTo#e1037f92 channel_id:long = MessageAction;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **channel\_id** | [long](/type/long.md) | The supergroup it was migrated to |

### Type
[MessageAction](/type/MessageAction.md)
