# starGiftAttributePattern

A [sticker](/api/stickers.md) applied on the backdrop of a [collectible gift »](/api/gifts.md) using a repeating pattern.

```tl
starGiftAttributePattern#4e7085ea name:string document:Document rarity:StarGiftAttributeRarity = StarGiftAttribute;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **name** | [string](/type/string.md) | Name of the symbol |
| **document** | [Document](/type/Document.md) | The symbol |
| **rarity** | [StarGiftAttributeRarity](/type/StarGiftAttributeRarity.md) | Rarity of this pattern. |

### Type
[StarGiftAttribute](/type/StarGiftAttribute.md)
