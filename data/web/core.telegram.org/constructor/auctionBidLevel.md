# auctionBidLevel

Describes a bid in an [auction](/api/auctions.md).

```tl
auctionBidLevel#310240cc pos:int amount:long date:int = AuctionBidLevel;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **pos** | [int](/type/int.md) | Position of the bid. |
| **amount** | [long](/type/long.md) | Amount of the bid in [Telegram Stars](/api/stars.md). |
| **date** | [int](/type/int.md) | Date when the bid was placed. |

### Type
[AuctionBidLevel](/type/AuctionBidLevel.md)
