### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **channel** | [InputChannel](/type/InputChannel.md) | Supergroup ID |
| **enabled** | [Bool](/type/Bool.md) | Enable or disable forum functionality |
| **tabs** | [Bool](/type/Bool.md) | If true enables the tabbed forum UI, otherwise enables the list-based forum UI. |

### Result
[Updates](/type/Updates.md)

### Only users can use this method

### Possible errors

| Code | Type | Description |
| --- | --- | --- |
| 400 | CHANNEL\_INVALID | The provided channel is invalid. |
| 400 | CHAT\_ADMIN\_REQUIRED | You must be an admin in this chat to do this. |
| 400 | CHAT\_DISCUSSION\_UNALLOWED | You can't enable forum topics in a discussion group linked to a channel. |
| 400 | CHAT\_ID\_INVALID | The provided chat id is invalid. |
| 400 | CHAT\_NOT\_MODIFIED | No changes were made to chat information because the new information you passed is identical to the current information. |
