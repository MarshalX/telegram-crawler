The [messages.updatePinnedMessage](/method/messages.updatePinnedMessage.md) method can be used to pin or unpin a specific message in an arbitrary chat.  
The `unpin` flag specifies whether to unpin or pin the message, and `pm_oneside` specifies whether the message should only be pinned on the local side of a one-to-one chat.  

[messages.unpinAllMessages](/method/messages.unpinAllMessages.md) can be used to unpin all messages in a chat.  

When pinning or unpinning messages, an [updatePinnedMessages](/constructor/updatePinnedMessages.md) or [updatePinnedChannelMessages](/constructor/updatePinnedChannelMessages.md) update will be emitted, containing IDs of pinned or unpinned messages.  

Pinned messages will also have the `pinned` flag of [message](/constructor/message.md) set.
