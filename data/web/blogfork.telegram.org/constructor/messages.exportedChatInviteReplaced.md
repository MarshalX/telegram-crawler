# messages.exportedChatInviteReplaced

The specified chat invite was replaced with another one

```tl
messages.exportedChatInviteReplaced#222600ef invite:ExportedChatInvite new_invite:ExportedChatInvite users:Vector<User> = messages.ExportedChatInvite;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **invite** | [ExportedChatInvite](/type/ExportedChatInvite.md) | The replaced chat invite |
| **new\_invite** | [ExportedChatInvite](/type/ExportedChatInvite.md) | The invite that replaces the previous invite |
| **users** | [Vector](/type/Vector%20t)&lt;[User](/type/User.md)&gt; | Mentioned users |

### Type
[messages.ExportedChatInvite](/type/messages.ExportedChatInvite.md)
