# updateStoriesStealthMode

Indicates that [stories stealth mode](/api/stories.md#stealth-mode) was activated.

```tl
updateStoriesStealthMode#2c084dc1 stealth_mode:StoriesStealthMode = Update;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **stealth\_mode** | [StoriesStealthMode](/type/StoriesStealthMode.md) | Information about the current [stealth mode](/api/stories.md#stealth-mode) session. |

### Type
[Update](/type/Update.md)
