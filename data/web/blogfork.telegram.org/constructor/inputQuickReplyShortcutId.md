# inputQuickReplyShortcutId

Selects a [quick reply shortcut](/api/business.md#quick-reply-shortcuts) by its numeric ID.

```tl
inputQuickReplyShortcutId#1190cf1 shortcut_id:int = InputQuickReplyShortcut;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **shortcut\_id** | [int](/type/int.md) | Shortcut ID. |
