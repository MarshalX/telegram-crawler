# starsTransactionPeerPremiumBot

Describes a [Telegram Star](/api/stars.md) transaction made using [@PremiumBot](https://t.me/premiumbot) (i.e. using the [inputInvoiceStars](/constructor/inputInvoiceStars.md) flow described [here »](/api/stars.md#buying-or-gifting-stars)).

```tl
starsTransactionPeerPremiumBot#250dbaf8 = StarsTransactionPeer;
```

### Parameters

This constructor does not require any parameters.

### Type
[StarsTransactionPeer](/type/StarsTransactionPeer.md)

### Related pages

#### [Telegram Stars](/api/stars.md)
Telegram Stars are virtual items that allow users to purchase digital goods and services from bots and mini apps inside the Telegram ecosystem, send gifts to content creators on the Telegram platform, and more.

#### [inputInvoiceStars](/constructor/inputInvoiceStars.md)
Used to top up the [Telegram Stars](/api/stars.md) balance of the current account or someone else's account, or to start a [Telegram Star giveaway »](/api/giveaways.md#star-giveaways).
