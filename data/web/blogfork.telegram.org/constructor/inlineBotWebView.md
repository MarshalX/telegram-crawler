# inlineBotWebView

Specifies an [inline mode mini app](/api/bots/webapps.md#inline-mode-mini-apps) button, shown on top of the inline query results list.

```tl
inlineBotWebView#b57295d5 text:string url:string = InlineBotWebView;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **text** | [string](/type/string.md) | Text of the button |
| **url** | [string](/type/string.md) | Webapp URL |

### Type
[InlineBotWebView](/type/InlineBotWebView.md)
