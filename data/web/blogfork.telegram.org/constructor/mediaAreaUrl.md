# mediaAreaUrl

Represents a [URL media area](/api/stories.md#urls).

```tl
mediaAreaUrl#37381085 coordinates:MediaAreaCoordinates url:string = MediaArea;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **coordinates** | [MediaAreaCoordinates](/type/MediaAreaCoordinates.md) | The size and location of the media area corresponding to the URL button on top of the story media. |
| **url** | [string](/type/string.md) | URL to open when clicked. |

### Type
[MediaArea](/type/MediaArea.md)
