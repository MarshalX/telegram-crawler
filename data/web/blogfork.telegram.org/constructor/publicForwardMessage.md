# publicForwardMessage

Contains info about a forward of a [story](/api/stories.md) as a message.

```tl
publicForwardMessage#1f2bf4a message:Message = PublicForward;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **message** | [Message](/type/Message.md) | Info about the message with the reposted story. |

### Type
[PublicForward](/type/PublicForward.md)
