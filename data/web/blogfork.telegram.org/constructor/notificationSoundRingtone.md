# notificationSoundRingtone

A specific previously uploaded notification sound should be used

```tl
notificationSoundRingtone#ff6c8049 id:long = NotificationSound;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **id** | [long](/type/long.md) | Document ID of notification sound uploaded using [account.uploadRingtone](/method/account.uploadRingtone.md) |

### Type
[NotificationSound](/type/NotificationSound.md)

### Related pages

#### [account.uploadRingtone](/method/account.uploadRingtone.md)
Upload notification sound, use [account.saveRingtone](/method/account.saveRingtone.md) to convert it and add it to the list of saved notification sounds.
