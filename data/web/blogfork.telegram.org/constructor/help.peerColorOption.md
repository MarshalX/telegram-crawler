# help.peerColorOption

Contains info about a [color palette »](/api/colors.md).

```tl
help.peerColorOption#adec6ebe flags:# hidden:flags.0?true color_id:int colors:flags.1?help.PeerColorSet dark_colors:flags.2?help.PeerColorSet channel_min_level:flags.3?int group_min_level:flags.4?int = help.PeerColorOption;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **flags** | [\#](/type/%23) | Flags, see [TL conditional fields](/mtproto/TL-combinators.md#conditional-fields) |
| **hidden** | [flags](/mtproto/TL-combinators.md#conditional-fields).0?[true](/constructor/true.md) | Whether this palette should not be displayed as an option to the user when choosing a palette to apply to profile pages or message accents. |
| **color\_id** | [int](/type/int.md) | Palette ID. |
| **colors** | [flags](/mtproto/TL-combinators.md#conditional-fields).1?[help.PeerColorSet](/type/help.PeerColorSet.md) | Light mode palette. \
Will be empty for IDs `0` to `6` inclusive, in which case a palette containing a single color from the following colors should be used: red, orange, violet, green, cyan, blue, pink for indexes 0 to 6 (i.e. the same colors used for the [randomized fallback color palette](/api/colors.md#randomized-fallback-color-palette)). |
| **dark\_colors** | [flags](/mtproto/TL-combinators.md#conditional-fields).2?[help.PeerColorSet](/type/help.PeerColorSet.md) | Dark mode palette. Optional, defaults to the palette in `colors` (or the autogenerated palette for IDs `0` to `6`) if absent. |
| **channel\_min\_level** | [flags](/mtproto/TL-combinators.md#conditional-fields).3?[int](/type/int.md) | Channels can use this palette only after reaching at least the [boost level](/api/boost.md) specified in this field. |
| **group\_min\_level** | [flags](/mtproto/TL-combinators.md#conditional-fields).4?[int](/type/int.md) | Supergroups can use this palette only after reaching at least the [boost level](/api/boost.md) specified in this field. |
