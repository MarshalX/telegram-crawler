# foundStory

A story found using [global story search »](/api/stories.md#searching-stories).

```tl
foundStory#e87acbc0 peer:Peer story:StoryItem = FoundStory;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **peer** | [Peer](/type/Peer.md) | The peer that posted the story. |
| **story** | [StoryItem](/type/StoryItem.md) | The story. |
