# messages.historyImportParsed

Contains information about a chat export file [generated by a foreign chat app, click here for more info](/api/import.md).  
If neither the `pm` or `group` flags are set, the specified chat export was generated from a chat of unknown type.

```tl
messages.historyImportParsed#5e0fb7b9 flags:# pm:flags.0?true group:flags.1?true title:flags.2?string = messages.HistoryImportParsed;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **flags** | [\#](/type/%23) | Flags, see [TL conditional fields](/mtproto/TL-combinators.md#conditional-fields) |
| **pm** | [flags](/mtproto/TL-combinators.md#conditional-fields).0?[true](/constructor/true.md) | The chat export file was generated from a private chat. |
| **group** | [flags](/mtproto/TL-combinators.md#conditional-fields).1?[true](/constructor/true.md) | The chat export file was generated from a group chat. |
| **title** | [flags](/mtproto/TL-combinators.md#conditional-fields).2?[string](/type/string.md) | Title of the chat. |
