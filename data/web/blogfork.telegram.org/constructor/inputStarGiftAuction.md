# inputStarGiftAuction

Used to fetch [auctions](/api/auctions.md) using the ID of the linked [collectible gift](/api/gifts.md#collectible-gifts).

```tl
inputStarGiftAuction#2e16c98 gift_id:long = InputStarGiftAuction;
```

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **gift\_id** | [long](/type/long.md) | [Collectible gift ID](/api/gifts.md#collectible-gifts) |

### Type
[InputStarGiftAuction](/type/InputStarGiftAuction.md)
