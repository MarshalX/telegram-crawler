# phone.deleteConferenceCallParticipants

Remove participants from a [conference call »](/api/end-to-end/group-calls.md#removing-a-participant).

Exactly one of the `only_left` and `kick` flags must be set.

### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **flags** | [\#](/type/%23) | Flags, see [TL conditional fields](/mtproto/TL-combinators.md#conditional-fields) |
| **only\_left** | [flags](/mtproto/TL-combinators.md#conditional-fields).0?[true](/constructor/true.md) | Whether this is a removal of members that already left the conference call. |
| **kick** | [flags](/mtproto/TL-combinators.md#conditional-fields).1?[true](/constructor/true.md) | Whether this is a forced removal of active members in a conference call. |
| **call** | [InputGroupCall](/type/InputGroupCall.md) | Conference from which to remove participants |
| **ids** | [Vector](/type/Vector%20t)&lt;[long](/type/long.md)&gt; | User IDs to remove from the conference and E2E blockchain |
| **block** | [bytes](/type/bytes.md) | Main-chain block removing the specified users and establishing a new shared key, see [removing a participant »](/api/end-to-end/group-calls.md#removing-a-participant) |

### Result
[Updates](/type/Updates.md)
