### Parameters

| Name | Type | Description |
| --- | :---: | --- |
| **flags** | [\#](/type/%23) | Flags, see [TL conditional fields](/mtproto/TL-combinators.md#conditional-fields) |
| **muted** | [flags](/mtproto/TL-combinators.md#conditional-fields).0?[true](/constructor/true.md) | If set, mute our microphone when joining the call (can only be used if `join` is set). |
| **video\_stopped** | [flags](/mtproto/TL-combinators.md#conditional-fields).2?[true](/constructor/true.md) | If set, our video stream is disabled (can only be used if `join` is set). |
| **join** | [flags](/mtproto/TL-combinators.md#conditional-fields).3?[true](/constructor/true.md) | If set, also join the call, otherwise just create the call link. |
| **random\_id** | [int](/type/int.md) | Unique client message ID required to prevent creation of duplicate group calls. See [here »](/api/updates.md#updatemessageid-updates) for more info on random ID deduplication and updateMessageID mapping. |
| **public\_key** | [flags](/mtproto/TL-combinators.md#conditional-fields).3?[int256](/type/int256.md) | Fresh E2E public key for the creator (can only be used if `join` is set). |
| **block** | [flags](/mtproto/TL-combinators.md#conditional-fields).3?[bytes](/type/bytes.md) | Initial main-chain block for subchain `0` (can only be used if `join` is set). |
| **params** | [flags](/mtproto/TL-combinators.md#conditional-fields).3?[DataJSON](/type/DataJSON.md) | Join payload generated by the local call engine (can only be used if `join` is set). |
