# InputBotApp

Used to fetch information about a [direct link Mini App](/api/bots/webapps.md#direct-link-mini-apps)

```tl
inputBotAppID#a920bd7a id:long access_hash:long = InputBotApp;
inputBotAppShortName#908c0407 bot_id:InputUser short_name:string = InputBotApp;
```

### Constructors

| Constructor | Description |
| --- | --- |
| [inputBotAppID](/constructor/inputBotAppID.md) | Used to fetch information about a [direct link Mini App](/api/bots/webapps.md#direct-link-mini-apps) by its ID |
| [inputBotAppShortName](/constructor/inputBotAppShortName.md) | Used to fetch information about a [direct link Mini App](/api/bots/webapps.md#direct-link-mini-apps) by its short name |
